    What happens
    • The token stays on this machine, in a 0600 file next to the gateway config.
    • The command adds only the token's hash on the host. Pasting it twice changes nothing.
    • Check adds the host only after it answers with this name and the operator role.
    • Cancel removes the token here. If the command already ran, revoke the name on the host too.
